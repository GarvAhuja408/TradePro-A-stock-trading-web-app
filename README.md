# TradePro — Stock Trading Web App

TradePro is a full-stack stock trading web application built using the MERN stack. It includes user authentication, holdings, positions, orders, and a dedicated trading dashboard.

## Features

* User Authentication with JWT & Cookies
* Trading Dashboard
* Holdings & Positions
* Order Management
* Portfolio Analytics
* REST APIs
* MongoDB Database

## Tech Stack

Frontend: React.js, Axios, React Router
Dashboard: React.js, Material UI, Chart.js
Backend: Node.js, Express.js, MongoDB, Mongoose
Authentication: JWT, bcryptjs, Cookies
Deployment: Vercel, Render, MongoDB Atlas

## Run Locally

```bash
git clone https://github.com/GarvAhuja408/TradePro-A-stock-trading-web-app.git

cd TradePro-A-stock-trading-web-app
```

Install dependencies in `backend`, `frontend`, and `dashboard`:

```bash
npm install
```

Start the applications:

```bash
npm run dev
```
